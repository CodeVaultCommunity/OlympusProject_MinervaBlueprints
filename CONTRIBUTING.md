# Contributing

[Português](CONTRIBUTING.pt-br.md) · [Agent guide](AGENTS.md) · [Release procedure](docs/releasing.md)

Select Alpha-v0.1.0 explicitly and read its normative model and profile. The current edition is unpublished; its in-place revision is authorized. Keep both languages aligned and preserve upstream snapshot bytes. Record changes in the changelog and requirement coverage.

Keep source-model integration documentary. Do not add an Atlas reader, translator or engine. Example changes preserve the official source contracts and identify new L2 decisions. Validate declarations separately from semantic review and actual domain execution.

Install development/runtime dependencies in an external environment. Run root documentation/distribution tests and edition tests/examples/counterexamples. Record real evidence; generate the inventory only after the final intended files are staged. Commit locally. Remote publication requires explicit authorization.
